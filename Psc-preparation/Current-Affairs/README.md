# Weekly Current Affairs Test — how it works

**For students:** every Wednesday a new test card appears automatically on
[`index.html`](index.html) with that Wednesday's **Nepali (BS) date**. Click
**Give Exam** → timed exam (same engine as `/Psc-preparation/Test/…`: full-screen,
timer, question palette, auto-submit, instant result + review, one attempt only).

**For the site owner — publishing a new Wednesday's test (2 minutes, no HTML edit):**

1. Open [`tests.js`](tests.js).
2. Copy the existing entry, paste it at the top of `window.CA_TESTS`, and change
   the date key to the new Wednesday's **BS date** in `YYYY-MM-DD` format
   (Baisakh = 01 … Chaitra = 12). Example: 28 Ashwin 2083 → `"2083-06-28"`.
3. Replace `name`, `details` and the `questions` list.  
   Each question: `{ question: "…", options: ["…","…","…","…"], correct: 0 }`
   where `correct` is the index (0–3) of the right option.
   Time limit is automatic: 0.8 minute per question (25 questions → 20 minutes).
4. Save/commit. The Wednesday button automatically switches from
   **“Questions coming soon”** to **“Give Exam”**.

> Notes
> - The Wednesday cards are generated by `current-affairs.js` from the series
>   start (Wednesday 14 Oct 2026 AD = 28 Ashwin 2083 BS). To change the start,
>   edit `SERIES_START_AD` there.
> - AD → BS conversion is in `nepali-date.js` (BS calendar table 2070–2090 BS).
> - The exam page is `exam.html?date=YYYY-MM-DD` (BS date). An unknown date
>   shows the “Questions coming soon” panel instead of a broken test.
