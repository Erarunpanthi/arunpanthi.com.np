Slope Deflection Method

Featured question

While using slope deflection method, in which direction is moment taken as positive?

  1. Clockwise
  2. Anti-clockwise
  3. Depends upon case
  4. Depends upon loading
A. Clockwise

Clockwise moments are taken as positive while using the slope deflection method. It is a displacement method used for analysing statically indeterminate beams and frames.

Static Indeterminacy

MCQ 4

Degree of static indeterminacy of a rigid-jointed plane frame having 15 members, 3 reaction components and 14 joints is:

  1. 3
  2. 2
  3. 6
  4. 8
C. 6

For a rigid-jointed plane frame, the degree of static indeterminacy is 3m + r − 3j. Therefore, 3(15) + 3 − 3(14) = 6.
MCQ 5

If there are m unknown member forces, r unknown reaction components and j number of joints, then the degree of static indeterminacy of a pin-jointed plane frame is given by:

  1. m − r + 2j
  2. m + r − 2j
  3. m + r + 2j
  4. m + r − 3j
B. m + r − 2j
